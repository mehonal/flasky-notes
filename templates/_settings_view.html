Vault Context (let AI read your notes)
Allow Vault Context
Vault Context lets the AI read relevant notes from your vault when answering. Each message triggers a private on-device search; the most relevant notes (titles + contents) are decrypted and sent to your AI provider (Ollama) as context. Your Flasky server never sees this plaintext. The AI provider will receive and read the relevant note contents. Enable per conversation in AI chat.
{% if ui_settings.vault_context_allowed %}
How many of the most relevant notes to attach as context per message (1–50).
Total character budget for vault context per message (1000–200000). Notes are added in relevance order until the budget is reached.
{% endif %}

AI Web Search
Allow AI Web Search
AI Web Search lets the AI search the web and fetch pages via Ollama's web search API when answering. Use with caution: the AI generates its own search queries (including rephrasing your question), and your search provider (Ollama) is responsible for how it handles those queries and any fetched page contents — review their privacy policy. Your Flasky server relays this traffic but does not store it. Enable per conversation in AI chat after acknowledging a warning.
{% if ui_settings.ai_web_search_allowed %}
How many rounds of web searches/fetches the AI may perform per message (1–10).
Each search/fetch result is truncated to this many characters before being fed back to the AI (500–50000).
How long to wait for each web search/fetch request before giving up (5–120 seconds).
